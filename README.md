# 💇‍♀️ BeautySalon

> Modern beauty salon booking & management platform.

---

## ✨ About

BeautySalon is a stylish platform designed for booking hairdressing and beauty services easily and quickly.  
It helps clients find services, choose specialists, and schedule appointments online.

---

## 💅 Services

- 💇 Haircuts & styling
- 🎨 Hair coloring
- 💆‍♀️ Hair treatments & care
- 💄 Makeup services
- 💅 Manicure & pedicure
- 📅 Online appointment booking

---

## 🚀 Features

- 📲 Easy online booking system
- 👩‍🎨 Stylist profiles & ratings
- ⏰ Schedule management
- 💳 Service price list
- 🔔 Appointment reminders
- 🌙 Modern responsive design

---

## 🎯 Mission

To make beauty services more accessible, convenient, and enjoyable for everyone.

---

## 🛠️ Technologies

- HTML / CSS
- JavaScript
- React (optional)
- Node.js
- MongoDB
- Tailwind CSS
